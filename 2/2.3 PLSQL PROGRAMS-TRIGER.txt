2.3 PL/SQL PROGRAMS-TRIGER

1. Create a trigger to handle updates to the Customer table.
mysql> delimiter //
mysql> create trigger cust_update after update on customer for each row
    -> begin
    -> insert into customer_log values(old.id,old.name,now());
    -> end //
Query OK, 0 rows affected (0.01 sec)

mysql> delimiter ;
mysql> update customer set name='Arya' where id=111;
Query OK, 0 rows affected (0.01 sec)
Rows matched: 1  Changed: 0  Warnings: 0

mysql> select * from customer_log;
+------+------+---------------------+
| id   | name | updated_at          |
+------+------+---------------------+
|  111 | Arya | 2026-04-14 11:36:17 |
+------+------+---------------------+
1 row in set (0.00 sec)


2. Create a trigger to handle inserts to the product relation (if price<5 then set price to 10).
mysql> DELIMITER //
mysql> CREATE TRIGGER product_insert
    -> BEFORE INSERT ON product
    -> FOR EACH ROW
    -> BEGIN
    ->     IF NEW.price < 5 THEN
    ->         SET NEW.price = 10;
    ->     END IF;
    -> END //
Query OK, 0 rows affected (0.01 sec)

mysql> DELIMITER ;
mysql> INSERT INTO product VALUES (44, 'Eraser', 3);
Query OK, 1 row affected (0.01 sec)

mysql> SELECT * FROM product WHERE pid = 44;
+-----+--------+-------+
| pid | pname  | price |
+-----+--------+-------+
|  44 | Eraser | 10.00 |
+-----+--------+-------+
1 row in set (0.00 sec)
