6. Display the purchase product details of the customer 'Arya'.
mysql> SELECT pname, price
    -> FROM product
    -> WHERE pid IN (
    ->     SELECT pid
    ->     FROM invoice_item
    ->     WHERE inv_id IN (
    ->         SELECT inv_id
    ->         FROM invoice_master
    ->         WHERE cust_id IN (
    ->             SELECT id
    ->             FROM customer
    ->             WHERE name = 'Arya'
    ->         )
    ->     )
    -> );
+-------+-------+
| pname | price |
+-------+-------+
| Pen   | 10.20 |
+-------+-------+
1 row in set (0.00 sec)
